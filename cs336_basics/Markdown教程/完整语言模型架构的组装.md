## 0. 阅读前的准备

### 0.1 一句话版本

> **语言模型就是一台“下一个 token 预测机”：把 token ID 变成向量，反复用 Transformer Block 加工，最后把每个位置的向量映射到词表上的打分（logits），再从中选出下一个 token。**

整条链路：

```text
token IDs (B, T)
   │  Embedding
   ▼
向量 (B, T, D)
   │  N × Transformer Block（注意力 + FFN + 残差 + 归一化）
   ▼
向量 (B, T, D)
   │  Final RMSNorm
   ▼
向量 (B, T, D)
   │  LM head（D → V）
   ▼
logits (B, T, V)
   │  softmax（推理） / cross entropy（训练）
   ▼
概率 (B, T, V) / loss（标量）
```

一句话记忆：

> **Embedding 负责“把词变成数”，Block 负责“反复加工”，LM head 负责“把数变回词表上的分数”。**

### 0.2 符号表

| 符号 | 含义 | 一句话解释 |
| --- | --- | --- |
| $B$ | batch size | 一次处理多少条序列 |
| $T$ | sequence length | 一条序列有多少个 token |
| $D$ 或 $d_{model}$ | 隐藏维度 | 每个 token 用多少个数表示 |
| $H$ | num_heads | 注意力头数 |
| $d_{head}$ | 每个头的维度 | $D/H$ |
| $d_{ff}$ | FFN 中间维度 | SwiGLU 内部先升到多宽 |
| $V$ | vocab size | 词表大小，也就是有多少个候选 token |
| $\Theta$ | RoPE 的底数 | 通常取 10000 |
| logits | 未归一化分数 | 可以是任意实数，不是概率 |

### 0.3 你需要的前置知识

1. **矩阵乘法**：$(B,T,D)\times(D,d_{ff})\to(B,T,d_{ff})$；
2. **查表**：用整数 ID 去矩阵里取某一行；
3. **softmax**：把一组分数变成“加起来等于 1”的概率；
4. **交叉熵**：衡量“给正确答案分配的概率”有多低；
5. **残差/归一化**：形状不变，只是数值上的加减和缩放。

### 0.4 全链路图（先有个整体印象）

```text
输入 IDs: (B, T)
   │
   ▼
┌─────────────────────────────┐
│ Token Embedding             │  查表 (V, D)
│   (B, T) → (B, T, D)        │
└─────────────────────────────┘
   │
   ▼
┌─────────────────────────────┐
│ Transformer Block × N       │
│                             │
│  x ─► RMSNorm ─► Attention ─► (+) ─► y
│  y ─► RMSNorm ─► SwiGLU ───► (+) ─► z
│                             │
└─────────────────────────────┘
   │
   ▼
Final RMSNorm: (B, T, D)
   │
   ▼
LM head: (B, T, D) → (B, T, V)
   │
   ▼
logits: (B, T, V)
   │
   ├── 训练：cross entropy（内部做 log-softmax）
   └── 推理：softmax → 采样 → 下一个 token
```

## 1. 架构总览：从 ID 到 Logits

### 1.1 第一步：输入是 token ID

模型不认识字符串，只认识整数。分词器把文本切成 token，再映射成 ID：

```text
"Hello world" → ["Hello", " world"] → [15496, 995]
```

输入张量：

$$
\text{ids}\in\mathbb{Z}^{B\times T}
$$

其中 `ids[b, t]` 是第 $b$ 条序列第 $t$ 个 token 的编号，取值范围是 $[0,V-1]$。

> 注意：ID 本身没有语义。`42` 和 `43` 挨得近，不代表它们的含义相近；ID 只是查表用的行号。

### 1.2 第二步：Embedding，把 ID 变成向量

Embedding 是一张形状为 $(V,D)$ 的大表：

```text
             D 维
token 0  → [ 0.31, -1.02,  0.88, ... ]
token 1  → [-0.44,  0.15,  1.30, ... ]
  ...
token V-1→ [ 0.77,  0.02, -0.61, ... ]
```

查表：

$$
x_{b,t}=\text{Embedding}[\text{ids}_{b,t}]
$$

形状变化：

$$
(B,T)\longrightarrow(B,T,D)
$$

作用：

- 把离散 ID 变成连续向量；
- 让语义相近的 token 在向量空间里靠近；
- 给后续的注意力和 FFN 提供可计算的输入。

> 这张表里的数字是**训练学出来的**，不是人写的。

### 1.3 第三步：N 个 Transformer Block

每个 Block 做两件事：

1. **注意力**：让每个 token 看其他 token，交换信息；
2. **FFN**：对每个 token 独立做非线性加工。

每个子层都包着：

- RMSNorm（归一化）；
- 残差连接（把结果加回主干）。

Pre-Norm 公式：

$$
y=x+\operatorname{MHA}(\operatorname{RMSNorm}(x))
$$

$$
z=y+\operatorname{SwiGLU}(\operatorname{RMSNorm}(y))
$$

形状：

$$
(B,T,D)\longrightarrow(B,T,D)
$$

重复 $N$ 次：

$$
x_{l+1}=\operatorname{Block}_l(x_l),\qquad l=1,\dots,N
$$

> Block 不改变形状、不改变序列长度，只改变每个位置的特征。详细解释见 `Transformer_Block.md`。

### 1.4 第四步：Final RMSNorm

走完 $N$ 个 Block 后，残差流的范数可能已经变大。送进 LM head 之前，要再做一次归一化：

$$
h=\operatorname{RMSNorm}(x_N)
$$

形状不变：

$$
(B,T,D)\longrightarrow(B,T,D)
$$

> Final Norm 属于**模型级**组件，不属于单个 Block。`run_transformer_block` 不包含它，`run_transformer_lm` 才包含。

### 1.5 第五步：LM head，把向量映射到词表

LM head 是一个线性层，权重形状 $(V,D)$：

$$
\text{logits}=hW_{\text{lm}}^\top
$$

形状变化：

$$
(B,T,D)\longrightarrow(B,T,V)
$$

含义：对每个位置 $t$，模型给词表里每个 token 打一个分。分数越高，模型认为它越可能是下一个 token。

> **logits 不是概率**：它们可以是负数、可以大于 1、加起来也不等于 1。要得到概率，需要再做 softmax。

### 1.6 第六步：训练与推理的分叉

**训练**：

- 输入 `ids`，标签是错开一位的 `ids`；
- 一次前向得到所有位置的 logits；
- 用交叉熵计算 loss；
- 反向传播更新参数。

```text
输入:  [t0] [t1] [t2] [t3]
标签:      [t1] [t2] [t3] [t4]
```

**推理**：

- 输入 prompt；
- 取最后一个位置的 logits；
- softmax 得到概率；
- 按贪心/温度/top-p 采样一个 token；
- 把它接到序列末尾，重复。

> 训练时一次算 $T$ 个位置，效率高；推理时一次只生成一个 token，是自回归的。

### 1.7 形状总览

```text
ids:            (B, T)
embedding:      (B, T, D)
每个 Block:     (B, T, D) → (B, T, D)
final norm:     (B, T, D)
logits:         (B, T, V)
loss:           标量
```

**整条链路只有两次“维度突变”**：

1. Embedding：最后一维从“没有”变成 $D$；
2. LM head：最后一维从 $D$ 变成 $V$。

中间所有 Block 都保持 $(B,T,D)$ 不变。

## 2. 核心组件解析

### 2.1 Token Embedding（词嵌入）

**作用**：把整数 ID 变成连续向量。

**设计动机**：

- 模型不能直接对 ID 做有意义的数学运算；
- one-hot 维度等于词表大小，太稀疏；
- 学习到的稠密向量可以表达“相似性”。

**形状**：

| 输入 | 输出 | 权重 |
| --- | --- | --- |
| `(B,T)` 整数 | `(B,T,D)` 浮点 | `(V,D)` |

**类比**：给每个 token 发一张“身份证”，上面写着它的 $D$ 个特征。

> 作业要求自己实现 `EmbeddingModule`，但语义就是查表；用 `nn.Embedding` 也能帮助理解。

### 2.2 位置编码：RoPE

**问题**：注意力本身分不清顺序。把两个 token 对调，注意力算出来的结果也会跟着对调，但“谁在前谁在后”这件事丢了。

**RoPE 的做法**：把 q、k 看成平面上的箭头，按 token 的位置旋转一个角度：

$$
\theta_{t,i}=t\cdot\Theta^{-2i/d_{head}}
$$

$$
\begin{pmatrix}q'_{2i}\\q'_{2i+1}\end{pmatrix}
=
\begin{pmatrix}\cos\theta_{t,i}&-\sin\theta_{t,i}\\
\sin\theta_{t,i}&\cos\theta_{t,i}\end{pmatrix}
\begin{pmatrix}q_{2i}\\q_{2i+1}\end{pmatrix}
$$

**关键点**：

- 只作用于 **q 和 k**，不作用于 v；
- 在**拆头之后**作用，每个头用自己的 $d_{head}$；
- 旋转后两个 token 的 q·k 点积只依赖**相对距离**；
- 位置表是固定的，不需要训练；
- `theta` 通常取 10000，`max_seq_len` 决定预计算多长。

**形状**：

$$
(B,H,T,d_{head})\longrightarrow(B,H,T,d_{head})
$$

> 直观理解：位置越靠后，箭头转得越多；两个箭头都转之后，它们的夹角只和“相差多远”有关。

### 2.3 因果多头自注意力（Causal MHA）

**作用**：让每个 token 按相关度读取其他 token 的信息。

**步骤**：

1. 用三个线性层得到 Q、K、V：

$$
Q=xW_Q^\top,\quad K=xW_K^\top,\quad V=xW_V^\top
$$

2. 拆成 $H$ 个头：

$$
(B,T,D)\longrightarrow(B,H,T,d_{head})
$$

3. 打分并缩放：

$$
\text{scores}=\frac{QK^\top}{\sqrt{d_{head}}}
$$

4. 加因果掩码：未来位置填 $-\infty$，softmax 后权重为 0；
5. softmax 得到权重；
6. 加权求和：

$$
\text{out}=\operatorname{softmax}(\text{scores})V
$$

7. 合头、输出投影：

$$
(B,H,T,d_{head})\longrightarrow(B,T,D)
$$

**形状**：

| 张量 | 形状 |
| --- | --- |
| Q/K/V 拆头后 | `(B,H,T,d_head)` |
| 分数 | `(B,H,T,T)` |
| 注意力输出 | `(B,H,T,d_head)` |
| 合头后 | `(B,T,D)` |

**设计动机**：

- 每个头可以关注不同的模式（语法、指代、标点等）；
- 因果掩码保证训练时不能偷看未来；
- 缩放 $\sqrt{d_{head}}$ 防止分数过大、softmax 过尖。

> 详细推导见 `Attention.md`；Block 里的接线见 `Transformer_Block.md`。

### 2.4 残差连接

**公式**：

$$
y=x+F(x)
$$

**作用**：

- 给梯度一条不经过子层的直路；
- 让“恒等映射”成为默认选项；
- 让深层网络有机会至少不差于浅层。

**形状**：两边必须相同，所以 $F$ 的输出必须压回 $(B,T,D)$。

**类比**：原画 + 批注。批注可以很精彩，但原画始终还在。

### 2.5 RMSNorm（归一化）

**作用**：把每个 token 的向量尺度拉回稳定范围。

**公式**：

$$
\operatorname{RMSNorm}(x)=\frac{x}{\sqrt{\frac{1}{D}\sum_i x_i^2+\epsilon}}\odot g
$$

**特点**：

- 逐 token 计算，不跨 batch；
- 不减均值，只缩放；
- 增益 $g$ 初始化为 1；
- 先升 `float32` 再算，防止平方溢出。

**位置**：

- 每个子层前（Pre-Norm）；
- 所有 Block 之后（Final Norm）。

> 详细推导见 `RMSNorm.md`。

### 2.6 SwiGLU 前馈网络（FFN）

**公式**：

$$
\operatorname{SwiGLU}(x)=W_2\big(\operatorname{SiLU}(W_1x)\odot(W_3x)\big)
$$

**形状**：

$$
(B,T,D)\longrightarrow(B,T,d_{ff})\longrightarrow(B,T,D)
$$

**作用**：

- 逐位置的非线性加工；
- 门控让模型可以“按需放大/抑制”通道；
- 提供模型的大部分参数容量。

**设计动机**：

- 注意力只做跨 token 混合，不擅长逐位置的非线性变换；
- $d_{ff}$ 通常取 $\frac{8}{3}D$（等参数设计），并取 64 的倍数；
- 没有 bias。

> 详细推导见 `SwiGLU.md`。

### 2.7 LM head（输出投影）

**作用**：把每个位置的 $D$ 维向量映射到 $V$ 个词表分数。

**公式**：

$$
\text{logits}=hW_{\text{lm}}^\top,\qquad W_{\text{lm}}\in\mathbb{R}^{V\times D}
$$

**形状**：

$$
(B,T,D)\longrightarrow(B,T,V)
$$

**特点**：

- 通常不带 bias；
- 输出是 logits，不是概率；
- 有些模型让 LM head 和 token embedding 共享权重（weight tying），作业参考实现是分开的两套权重。

### 2.8 Softmax 与交叉熵（输出阶段）

**softmax**：

$$
p_i=\frac{e^{z_i}}{\sum_j e^{z_j}}
$$

把 logits 变成概率。数值稳定做法是先减去最大值。

**交叉熵**：

$$
\mathcal{L}=-\frac{1}{BT}\sum_{b,t}\log p_{b,t}\bigl(x_{b,t+1}\bigr)
$$

**关键点**：

- `F.cross_entropy` 接收的是 **logits**，内部会做 log-softmax；
- 不要先手动 softmax 再传给交叉熵，否则等于做了两次归一化；
- 模型本身通常返回 logits，把 softmax 留给训练/推理阶段。

### 3.4 参数量公式

假设标准多头注意力（每个投影 $D\times D$）、SwiGLU、无 bias、LM head 不共享：

| 组件 | 参数量 |
| --- | ---: |
| Token Embedding | $V\cdot D$ |
| 每个 Block 的注意力 | $4D^2$ |
| 每个 Block 的 FFN | $3D\cdot d_{ff}$ |
| 每个 Block 的两个 RMSNorm | $2D$ |
| Final RMSNorm | $D$ |
| LM head | $V\cdot D$ |

合计：

$$
N_{\text{params}}
=2VD+L\bigl(4D^2+3Dd_{ff}+2D\bigr)+D
$$

> 如果 LM head 和 embedding 共享权重（weight tying），总参数要减去 $V\cdot D$。作业参考实现是分开的。

### 3.5 两个配置的参数量

| --- | ---: | ---: |
| Embedding | 640,000 | 3,200 |
| 每个 Block | 41,088 | 10,304 |
| 全部 Block | 123,264 | 20,608 |
| Final Norm | 64 | 32 |
| LM head | 640,000 | 3,200 |
| **合计（不共享）** | **1,403,328** | **27,040** |

验证一个 Block：

- 注意力：$4\times64^2=16{,}384$；
- FFN：$3\times64\times128=24{,}576$；
- 两个 Norm：$2\times64=128$；
- 合计：$41{,}088$。

### 3.6 维度设计准则

| 参数 | 经验 |
| --- | --- |
| $D$ | 模型宽度，决定表示能力 |
| $H$ | 必须整除 $D$；$d_{head}=D/H$，常见 64/128 |
| $d_{ff}$ | 通常 $\frac{8}{3}D$，取 64 的倍数 |
| $V$ | 词表大小，影响 embedding 和 LM head 的参数 |
| $T$ | 不能超过 `context_length`，否则 RoPE 位置表越界 |
| $B$ | 受显存限制；不影响模型结构 |

> 具体推导见 `SwiGLU.md` 和 `RMSNorm.md`；这里只需要知道每个维度在哪个阶段出现。

## 4. 参考代码：一个可运行的完整 LM

下面是一个**完整可运行**的最小 decoder-only Transformer LM（纯 PyTorch，CPU 即可）。它包含：

- Token Embedding；
- RoPE；
- 因果多头注意力；
- SwiGLU FFN；
- Pre-Norm Block；
- Final RMSNorm；
- LM head；
- 训练 loss 与推理 softmax 的演示。

> 为了聚焦架构，代码用 `nn.Embedding`/`nn.Linear`；作业要求自己实现对应的 `EmbeddingModule`/`LinearModule`，但语义完全一样。

### 4.1 运行方式

```bash

```

只需要 PyTorch，CPU 即可。

### 4.2 完整代码

```python
"""完整 Transformer LM 最小示例（纯 PyTorch，CPU 可跑）。"""
import math

import torch
import torch.nn.functional as F
from torch import nn

torch.manual_seed(0)


class RMSNorm(nn.Module):
    def __init__(self, d_model, eps=1e-5):
        super().__init__()
        self.eps = eps
        self.weight = nn.Parameter(torch.ones(d_model))

    def forward(self, x):
        in_dtype = x.dtype
        x = x.to(torch.float32)
        rms = torch.sqrt(x.pow(2).mean(dim=-1, keepdim=True) + self.eps)
        return (x / rms * self.weight).to(in_dtype)


class SwiGLU(nn.Module):
    def __init__(self, d_model, d_ff):
        super().__init__()
        self.w1 = nn.Linear(d_model, d_ff, bias=False)
        self.w2 = nn.Linear(d_ff, d_model, bias=False)
        self.w3 = nn.Linear(d_model, d_ff, bias=False)

    def forward(self, x):
        return self.w2(F.silu(self.w1(x)) * self.w3(x))


def build_rope_cache(max_seq_len, d_head, theta=10000.0, device=None):
    """返回 cos/sin，形状都是 (max_seq_len, d_head/2)。"""
    inv_freq = 1.0 / (theta ** (torch.arange(0, d_head, 2, device=device).float() / d_head))
    positions = torch.arange(max_seq_len, device=device).float()
    freqs = torch.outer(positions, inv_freq)
    return freqs.cos(), freqs.sin()


def apply_rope(x, cos, sin):
    """x: (..., T, d_head)；cos/sin: (T, d_head/2)。"""
    x1 = x[..., 0::2]
    x2 = x[..., 1::2]
    out1 = x1 * cos - x2 * sin
    out2 = x1 * sin + x2 * cos
    return torch.stack([out1, out2], dim=-1).flatten(-2)


class CausalSelfAttention(nn.Module):
    def __init__(self, d_model, num_heads, max_seq_len, theta=10000.0):
        super().__init__()
        assert d_model % num_heads == 0
        self.d_model = d_model
        self.num_heads = num_heads
        self.head_dim = d_model // num_heads

        self.q_proj = nn.Linear(d_model, d_model, bias=False)
        self.k_proj = nn.Linear(d_model, d_model, bias=False)
        self.v_proj = nn.Linear(d_model, d_model, bias=False)
        self.out_proj = nn.Linear(d_model, d_model, bias=False)

        cos, sin = build_rope_cache(max_seq_len, self.head_dim, theta)
        self.register_buffer("cos", cos, persistent=False)
        self.register_buffer("sin", sin, persistent=False)

    def forward(self, x):
        B, T, D = x.shape
        q = self.q_proj(x).view(B, T, self.num_heads, self.head_dim).transpose(1, 2)
        k = self.k_proj(x).view(B, T, self.num_heads, self.head_dim).transpose(1, 2)
        v = self.v_proj(x).view(B, T, self.num_heads, self.head_dim).transpose(1, 2)

        q = apply_rope(q, self.cos[:T], self.sin[:T])
        k = apply_rope(k, self.cos[:T], self.sin[:T])

        scores = q @ k.transpose(-2, -1) / math.sqrt(self.head_dim)
        # 因果掩码：下三角（含对角线）为 True = 允许看；上三角是未来，屏蔽掉
        causal = torch.tril(torch.ones(T, T, dtype=torch.bool, device=x.device))
        scores = scores.masked_fill(~causal, float("-inf"))
        attn = torch.softmax(scores, dim=-1)
        out = attn @ v

        out = out.transpose(1, 2).contiguous().view(B, T, D)
        return self.out_proj(out)


class TransformerBlock(nn.Module):
    def __init__(self, d_model, num_heads, d_ff, max_seq_len, theta=10000.0):
        super().__init__()
        self.ln1 = RMSNorm(d_model)
        self.attn = CausalSelfAttention(d_model, num_heads, max_seq_len, theta)
        self.ln2 = RMSNorm(d_model)
        self.ffn = SwiGLU(d_model, d_ff)

    def forward(self, x):
        x = x + self.attn(self.ln1(x))
        x = x + self.ffn(self.ln2(x))
        return x


class TransformerLM(nn.Module):
    def __init__(self, vocab_size, context_length, d_model, num_layers, num_heads, d_ff, rope_theta=10000.0):
        super().__init__()
        self.context_length = context_length
        self.token_embeddings = nn.Embedding(vocab_size, d_model)
        self.layers = nn.ModuleList([
            TransformerBlock(d_model, num_heads, d_ff, context_length, rope_theta)
            for _ in range(num_layers)
        ])
        self.ln_final = RMSNorm(d_model)
        self.lm_head = nn.Linear(d_model, vocab_size, bias=False)

    def forward(self, token_ids):
        x = self.token_embeddings(token_ids)
        for block in self.layers:
            x = block(x)
        x = self.ln_final(x)
        return self.lm_head(x)


def main():
    B, T, V, D, L, H, F_ = 2, 8, 100, 32, 2, 4, 64
    model = TransformerLM(V, T, D, L, H, F_)
    ids = torch.randint(0, V, (B, T))
    logits = model(ids)

    print("输入 IDs 形状:", tuple(ids.shape))
    print("logits 形状  :", tuple(logits.shape))
    print("参数量       :", sum(p.numel() for p in model.parameters()))

    loss = F.cross_entropy(logits[:, :-1].reshape(-1, V), ids[:, 1:].reshape(-1))
    print("交叉熵 loss  :", round(loss.item(), 4))

    probs = torch.softmax(logits[:, -1], dim=-1)
    print("最后位置概率:", tuple(probs.shape), "每行和:", probs.sum(-1).tolist())


if __name__ == "__main__":
    main()
```

### 4.3 预期输出

```text

logits 形状  : (2, 8, 100)
参数量       : 27040
交叉熵 loss  : 4.5638
最后位置概率: (2, 100) 每行和: [1.0, 1.0]
```

> 随机初始化时，loss 接近 $\ln V=\ln100\approx4.605$；模型训练后会下降。这里的 4.5638 只是随机初始化的正常值。

### 4.4 逐段讲解

#### 4.4.1 RMSNorm

```python
def forward(self, x):
    in_dtype = x.dtype
    x = x.to(torch.float32)
    rms = torch.sqrt(x.pow(2).mean(dim=-1, keepdim=True) + self.eps)
    return (x / rms * self.weight).to(in_dtype)
```

- 每个 token 独立归一化；
- `mean(dim=-1)` 只在通道维求平均；
- 先升 `float32`，避免平方溢出；
- 增益 `weight` 逐通道缩放。

#### 4.4.2 SwiGLU

```python
def forward(self, x):
    return self.w2(F.silu(self.w1(x)) * self.w3(x))
```

- `w1` 支路做 SiLU，当门控；
- `w3` 支路是内容；
- 逐元素相乘后，`w2` 压回 `D`；
- 没有 bias。

#### 4.4.3 RoPE

```python
inv_freq = 1.0 / (theta ** (torch.arange(0, d_head, 2).float() / d_head))
positions = torch.arange(max_seq_len).float()
freqs = torch.outer(positions, inv_freq)
cos, sin = freqs.cos(), freqs.sin()
```

- `inv_freq` 是每个维度对的频率；
- `positions` 是 0 到 `max_seq_len-1`；
- 外积得到每个位置、每个频率的角度；
- `cos/sin` 是固定表，不参与训练。

```python
x1 = x[..., 0::2]
x2 = x[..., 1::2]
out1 = x1 * cos - x2 * sin
out2 = x1 * sin + x2 * cos
return torch.stack([out1, out2], dim=-1).flatten(-2)
```

- 相邻两维配成一对；
- 每对旋转一个角度；
- `stack` 后压平，保持维度顺序；
- 只对 q/k 调用，不对 v 调用。

#### 4.4.4 因果多头注意力

```python
q = self.q_proj(x).view(B, T, self.num_heads, self.head_dim).transpose(1, 2)
```

- 先投影，再拆头；
- `view` 只改解释方式，`transpose` 把头放到 batch 维后面；
- 得到 `(B,H,T,d_head)`。

```python
scores = q @ k.transpose(-2, -1) / math.sqrt(self.head_dim)
causal = torch.tril(torch.ones(T, T, dtype=torch.bool))   # True = 允许看
scores = scores.masked_fill(~causal, float("-inf"))
attn = torch.softmax(scores, dim=-1)
out = attn @ v
```

- 打分后缩放；
- 掩码约定是 `True = 允许`（和讲义、`F.scaled_dot_product_attention` 一致），
  所以填的是 `~causal`：下三角（含对角线）保留，上三角是未来，填 `-inf`；
- softmax 后未来权重为 0；
- 对 v 加权求和。

```python
out = out.transpose(1, 2).contiguous().view(B, T, D)
return self.out_proj(out)
```

- 合头回 `(B,T,D)`；
- `contiguous()` 是因为 `transpose` 后内存不连续，直接 `view` 会报错；
- 输出投影混合各头的信息。

#### 4.4.5 Block 与 LM

```python
def forward(self, x):
    x = x + self.attn(self.ln1(x))
    x = x + self.ffn(self.ln2(x))
    return x
```

- Pre-Norm：先归一化，再进子层，最后残差；
- 两个子层各有一个残差；
- 形状始终是 `(B,T,D)`。

```python
x = self.token_embeddings(token_ids)
for block in self.layers:
    x = block(x)
x = self.ln_final(x)
return self.lm_head(x)
```

- 先查表；
- 过 $L$ 个 Block；
- 最终归一化；
- LM head 输出 logits。

#### 4.4.6 训练 loss 与推理概率

```python
loss = F.cross_entropy(logits[:, :-1].reshape(-1, V), ids[:, 1:].reshape(-1))
```

- `logits[:, :-1]`：前 $T-1$ 个位置的预测；
- `ids[:, 1:]`：后 $T-1$ 个位置的真实 token；
- `reshape(-1, V)` 把 $(B,T-1,V)$ 展平成 $(B(T-1),V)$；
- `F.cross_entropy` 接收 logits，内部做 log-softmax。

```python
probs = torch.softmax(logits[:, -1], dim=-1)
```

- 推理时只取最后一个位置；
- softmax 得到词表概率；
- 可以再做温度/top-p 采样。

### 4.5 代码与公式对照表

| 代码 | 公式 | 作用 |
| --- | --- | --- |
| `token_embeddings(ids)` | $x=E[\text{ids}]$ | ID → 向量 |
| `q_proj/k_proj/v_proj` | $Q=xW_Q^\top$ 等 | 生成 Q/K/V |
| `apply_rope` | 旋转 q/k | 注入位置 |
| `q @ k.T / sqrt(d_head)` | $\frac{QK^\top}{\sqrt{d_{head}}}$ | 注意力分数 |
| `masked_fill(~causal, -inf)` | 加因果掩码（True = 允许） | 不能看未来 |
| `softmax(scores) @ v` | $\operatorname{softmax}(S)V$ | 加权取信息 |
| `out_proj` | $W_O$ | 混合各头 |
| `x + attn(ln1(x))` | $x+\operatorname{MHA}(\operatorname{RMSNorm}(x))$ | 第一个子层 |
| `x + ffn(ln2(x))` | $x+\operatorname{SwiGLU}(\operatorname{RMSNorm}(x))$ | 第二个子层 |
| `ln_final(x)` | $\operatorname{RMSNorm}(x)$ | 最终归一化 |
| `lm_head(x)` | $xW_{\text{lm}}^\top$ | 输出 logits |

### 4.6 小实验

**实验 1：改序列长度**

把 `T` 从 8 改成 4 或 16，确认 logits 形状跟着变，但 $D$ 和 $V$ 不变。注意 $T\le$ `context_length`。

**实验 2：改头数**

把 `H` 从 4 改成 2 或 8，观察 `d_head = D/H` 和注意力分数形状的变化。确保 $D$ 能被 $H$ 整除。

**实验 3：去掉 RoPE**

把 `q = apply_rope(...)` 和 `k = apply_rope(...)` 注释掉，模型仍然能跑，但位置信息丢失；在小数据上训练，效果通常会变差。

**实验 4：共享 embedding 和 LM head**

```python
self.lm_head.weight = self.token_embeddings.weight
```

观察参数量减少 $V\cdot D$。作业参考实现没有共享，测试时不要自行绑定。

**实验 5：改层数**

把 `L` 从 2 改成 1/4/8，观察参数量线性增长、logits 形状不变。

## 5. 仓库里的 Transformer_LM.py 逐段导读

> **想训练怎么办**：`cs336_basics/main_train.py` 里另有一套 `TransformerLM`，
> 零件相同（Embedding / RMSNorm / SwiGLU / 多头注意力），但所有参数都注册成
> `nn.Parameter`，可以直接交给优化器。下面这套 weights 写法只用于对拍和推理加载。

仓库里的 `cs336_basics/Transformer_LM.py` 采用**显式权重传入**的写法：构造时保存一个 `weights` 字典，forward 时逐层新建模块并 `load_state_dict`。它和本文 demo 的结构完全一致，只是“权重从哪来”不同。

### 5.1 整体结构

```python
class TransformerLM(nn.Module):
    def __init__(self, vocab_size, context_length, d_model, num_layers,
                 num_heads, d_ff, rope_theta, weights):
        ...
        self.weights = weights

    def forward(self, in_indices):
        # 1) Embedding
        # 2) for layer in range(num_layers): TransformerBlock
        # 3) Final RMSNorm
        # 4) LM head
        # 5) return logits（不 softmax）
```

### 5.2 forward 的关键步骤

```python
embedding_module = EmbeddingModule(self.vocab_size, self.d_model, device=None)
embedding_module.load_state_dict({
    "embedding_matrix": self.weights["token_embeddings.weight"]
})
embedding = embedding_module(in_indices)
```

- 从 `weights` 里取 `token_embeddings.weight`；
- 形状 `(V,D)`；
- 查表得到 `(B,T,D)`。

```python
for layer in range(self.num_layers):
    attn_q_proj_weight = self.weights[f"layers.{layer}.attn.q_proj.weight"]
    ...
    transformer_block = TransformerBlock(
        self.d_model, self.num_heads, self.d_ff,
        self.context_length, self.rope_theta,
        attn_q_proj_weight, attn_k_proj_weight,
        attn_v_proj_weight, attn_o_proj_weight,
        ln1_weight, ln2_weight,
        ffn_w1_weight, ffn_w2_weight, ffn_w3_weight,
        device=None,
    )
    embedding = transformer_block(embedding)
```

- 每一层从 `weights` 里取 9 组权重；
- 新建一个 `TransformerBlock`；
- 前向，形状保持 `(B,T,D)`。

```python
rms_norm = RMSNorm(self.d_model, eps=1e-5, device=None)
rms_norm.load_state_dict({"weight": self.weights["ln_final.weight"]})
out_norm = rms_norm(embedding)

linear_module = LinearModule(self.d_model, self.vocab_size, device=None)
linear_module.load_state_dict({"W": self.weights["lm_head.weight"]})
out_linear = linear_module(out_norm)
return out_linear
```

- 最终 RMSNorm；
- LM head：`LinearModule(d_model, vocab_size)`；
- 返回 logits，**没有 softmax**（注释也写了“作业不需要 softmax 归一化”）。

### 5.3 与本文 demo 的差异

| 点 | 本文 demo | 仓库 `Transformer_LM.py` |
| --- | --- | --- |
| 权重来源 | `nn.Parameter` 自己初始化 | 外部 `weights` 字典 |
| 模块创建 | `__init__` 里建好 | `forward` 里逐层新建 |
| 训练 | 可以直接训练 | 主要用于测试/前向 |
| 设备迁移 | `model.to(device)` 生效 | 普通 Tensor 不会自动搬 |
| 输出 | logits | logits |
| 结构 | 相同 | 相同 |

> 仓库写法是为了适配测试 adapter：测试会把参考权重传进来，逐层 `load_state_dict` 最直接。如果要真正训练，建议把模块和参数在 `__init__` 里注册好，这样优化器才能看到它们、`.to(device)` 才能搬动它们。

### 5.4 导入问题与修正（重要）

当前 `Transformer_LM.py` 开头的导入是：

```python
from transformer_block import TransformerBlock
from linear_and_embedding_module import LinearModule, EmbeddingModule
from rope import RoPE
from RMSnorm import RMSNorm
from SwiGLU import SwiGLU
from softmax import softmax
```

这些模块名和实际文件名不一致，Linux 下大小写敏感，直接运行会报 `ModuleNotFoundError`。按实际文件修正：

```python
from cs336_basics.Transformer_Block import TransformerBlock
from cs336_basics.Linear_Embedding_model import LinearModule, EmbeddingModule
from cs336_basics.RMSNorm import RMSNorm
```

- `RoPE`、`SwiGLU`、`softmax` 在 `Transformer_LM.py` 里没有直接用到（Block 内部会用 RoPE/SwiGLU），可以删掉；
- 如果从仓库根目录运行，建议用 `python -m cs336_basics.Transformer_LM`，或者确保根目录在 `PYTHONPATH` 里；
- 我本地用测试权重验证过：修正导入后，输出与 `test_transformer_lm` 快照的最大误差约 `7.6e-6`，低于测试容差 `1e-4`。

### 5.5 两个工程注意点

1. **模块在 forward 里新建**
   每次前向都会重新建 Embedding/Block/RMSNorm/Linear，并重新 `load_state_dict`。测试没问题，但训练时很慢，而且参数不会被注册到模型的 `parameters()` 里，优化器看不到。

2. **`weights` 是普通字典**
   里面的 Tensor 不是 `nn.Parameter` 或 buffer，`model.to("cuda")` 不会搬它们。当前 CPU 测试没问题；如果要上 GPU/训练，应该把权重注册成参数或 buffer。

> 结论：这份 `Transformer_LM.py` 作为“测试适配器版本”是对的；如果把它当训练代码，需要重构成“在 `__init__` 里建模块、注册参数”的写法。

### 6.2 权重键

| 键 | 形状 | 对应模块 |
| --- | --- | --- |
| `token_embeddings.weight` | `(V,D)` | Token Embedding |
| `layers.{i}.attn.q_proj.weight` | `(D,D)` | Q 投影 |
| `layers.{i}.attn.k_proj.weight` | `(D,D)` | K 投影 |
| `layers.{i}.attn.v_proj.weight` | `(D,D)` | V 投影 |
| `layers.{i}.attn.output_proj.weight` | `(D,D)` | 输出投影 |
| `layers.{i}.ln1.weight` | `(D,)` | 第一个 RMSNorm |
| `layers.{i}.ffn.w1.weight` | `(d_ff,D)` | SwiGLU 门控升维 |
| `layers.{i}.ffn.w2.weight` | `(D,d_ff)` | SwiGLU 降维 |
| `layers.{i}.ffn.w3.weight` | `(d_ff,D)` | SwiGLU 内容升维 |
| `layers.{i}.ln2.weight` | `(D,)` | 第二个 RMSNorm |
| `ln_final.weight` | `(D,)` | 最终 RMSNorm |
| `lm_head.weight` | `(V,D)` | 输出投影 |

没有 `bias` 键。

### 6.3 forward 顺序

必须严格按：

```text
ids
 → Embedding
 → for i in range(L): Block_i
 → ln_final
 → lm_head
 → logits
```

Block 内部：

```text
x + Attention(RMSNorm(x))
y + SwiGLU(RMSNorm(y))
```

### 6.5 常见错误对照表

| 现象 | 可能原因 | 修正 |
| --- | --- | --- |
| 输出形状是 `(B,T,D)` | 忘了 LM head | 加 `lm_head` |
| 输出形状是 `(B,V)` | 只取了最后一个位置 | 训练/测试需要 `(B,T,V)` |
| 数值和参考差很多 | 在模型里做了 softmax | 返回 logits，不 softmax |
| 权重键缺失 | 用了 `lm_head.weight` 以外的名字 | 对齐 state dict |
| 形状不匹配 | `lm_head` 权重转置 | 权重应为 `(V,D)` |
| `T > context_length` 报错 | RoPE 表越界 | 限制 $T$ 或扩展表 |
| 位置信息错乱 | RoPE 加在 v 上 | 只加在 q/k |
| 训练 loss 不下降 | 忘了残差/归一化 | 检查 Block |
| loss 是 `nan` | 掩码整行 `-inf` | 保留对角线 |
| 参数量多了 `V*D` | 误加了一套 embedding/LM head，或重复注册 | 检查是否多建了一套词表投影 |
| 输入 dtype 错 | `in_indices` 是浮点 | 用 `torch.long` |
| 只支持 3 维输入 | 写死了 `B,T,D` | 用 `...` 或展平前导维 |
| 测试超时 | forward 里反复建模块 | 测试可接受；训练要重构 |

## 7. 常见误区 FAQ

**Q1：logits 和概率有什么区别？**
logits 是未归一化的分数，可以是任意实数；softmax 之后才是概率。模型通常返回 logits。

**Q2：为什么模型不直接输出概率？**
训练时 `cross_entropy` 需要 logits（内部做 log-softmax），更数值稳定；推理时再按需 softmax/采样。

**Q3：为什么要有 Final Norm？**
Pre-Norm 的残差流没有归一化，范数会随深度增长；Final Norm 在 LM head 前把尺度拉回稳定范围。

**Q4：为什么没有 bias？**
现代 LLM 通常省略线性层和归一化的 bias，减少参数和计算；作业也要求无 bias。

**Q5：Embedding 和 LM head 要共享权重吗？**
不一定。共享（weight tying）能省参数，但作业参考实现是分开的两套权重；测试时按 state dict 来。

**Q6：为什么 RoPE 只作用在 q/k，不作用在 v？**
q/k 用来算“相关性”，需要位置信息；v 是要被取走的内容，旋转它没有语义收益。

**Q7：为什么要有因果掩码？**
训练时输入包含整段序列，如果不掩码，位置 $t$ 会看到 $t+1$，等于偷看答案。

**Q8：为什么 $T$ 不能超过 `context_length`？**
RoPE 的位置表只预计算到 `context_length`；超过会查表越界。推理时要限制长度或扩展位置表。

**Q9：为什么 FFN 的 $d_{ff}$ 比 $D$ 大？**
给模型更大的中间空间做非线性组合；通常取 $\frac{8}{3}D$，再压回 $D$ 接残差。

**Q10：为什么输出是 `(B,T,V)`，不是 `(B,V)`？**
训练时每个位置都要预测下一个 token；一次前向产生 $T$ 个预测。推理时才只取最后一个位置。

**Q11：为什么 loss 要错开一位？**
位置 $t$ 的 logits 应该预测 token $t+1$；所以 `logits[:, :-1]` 对应 `ids[:, 1:]`。

**Q12：为什么不能只用注意力？**
注意力做跨 token 混合，但缺少逐位置的非线性加工；FFN 提供这部分容量。

**Q13：仓库里的 `Transformer_LM.py` 在 forward 里建模块，能训练吗？**
能跑前向，但不适合训练：参数没注册、优化器看不到、设备迁移也麻烦。训练版应在 `__init__` 里建好模块。

```text

        → Embedding (B,T,D)
        → N × Block[ RMSNorm→Attn→+, RMSNorm→SwiGLU→+ ]

        → LM head (D→V)
        → logits (B,T,V)

关键形状:
        Q/K/V 拆头 (B,H,T,d_head)
        scores    (B,H,T,T)
        FFN 中间  (B,T,d_ff)

参数:
        Embedding V*D
        每 Block 4D² + 3D*d_ff + 2D
        Final Norm D
        LM head V*D

训练:   logits[:, :-1] vs ids[:, 1:] → cross_entropy
推理:   最后位置 logits → softmax → 采样
```
